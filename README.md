# sunlanchang.com

Personal homepage for Lanchang Sun. One static page, prerendered at build
time and served from a Cloudflare Worker.

Design source of truth: `design_handoff_sunlanchang_homepage/` (reference
HTML + handoff README with tokens and copy).

## Stack

- TanStack Start + TanStack Router, React 19, TypeScript
- Vite 8 + `@cloudflare/vite-plugin`
- Plain CSS: `src/styles/tokens.css` (design tokens) + `src/styles.css`
- Wrangler deploy to a Worker with a custom domain (`sunlanchang.com`)

No database, auth, or CMS. No dark mode, search, or tags (v1 scope).

## Commands

```sh
pnpm install
pnpm dev        # http://localhost:3100
pnpm build      # vite build (client + worker + prerender) && tsc --noEmit
pnpm preview    # serve the production build locally in workerd
pnpm run deploy # build + wrangler deploy (`run` is required: `pnpm deploy` is a pnpm built-in)
```

## Where things live

| What | File |
| --- | --- |
| All homepage copy (hero, Ciyo, experiments, about, footer) | `src/content/site.ts` |
| Notes list (hardcoded for v1) | `src/content/notes.ts` |
| Section components | `src/components/homepage/*.tsx` |
| Page assembly | `src/routes/index.tsx` |
| `<head>` (title, meta, favicon, stylesheet) | `src/routes/__root.tsx` |
| Scroll-reveal hook | `src/lib/use-reveal.ts` |
| Design tokens | `src/styles/tokens.css` |
| Worker entry | `src/server.ts` |
| Worker config | `wrangler.jsonc` |

`src/routeTree.gen.ts` is generated by the TanStack plugin on `dev`/`build`.

## Ciyo live preview

The dark band embeds `ciyo.url` in a lazy-loaded, sandboxed iframe. A
1440×900 desktop viewport scales to the panel width using ResizeObserver,
so the preview shows the same layout on desktop and mobile. Visitors can
interact with the preview or use “Open website” to open Ciyo in a new tab.

The preview URL and labels live in `src/content/site.ts`. The target site
must allow framing by `sunlanchang.com` for the preview to load.

## Notes (future)

Notes will be MDX files in the repo, prerendered. When they are wired, build
the list in `src/content/notes.ts` from their frontmatter (`title`, `date`)
and point each `href` at the note route.

## Deploy

`wrangler.jsonc` binds the Worker to `sunlanchang.com` as a custom domain
and disables the `workers.dev` subdomain. The first `pnpm deploy` creates
the DNS record for `sunlanchang.com` in the Cloudflare zone; any existing
record for the apex must be removed first or the deploy will fail.
